# 核心流程及涉及到的技术介绍

背后涉及到的东西大概是这样：

1. 采集：摄像头/麦克风调用，每个平台 API 不一样
2. 前处理：美颜、降噪、回声消除，要么用现成 SDK，要么自己写算法
3. 编码：H.264 / H.265 / AV1，参数调一调画质和延迟差几倍
4. 封装：FLV / MP4 / TS，根据传输协议选
5. 传输：RTMP / WebRTC / SRT / HLS，每种延迟和场景都不同
6. 服务端：CDN、转码、录制、鉴权
7. 解码 + 后处理：还要再做一遍前面的反向操作
8. 渲染：OpenGL / Metal / Vulkan，每个平台又不一样
9. 同步：音视频时间戳要对齐，不然口型对不上

这些步骤板块， 我写了无数遍，看了无数遍，就是停留在表面， 这个行业的东西多，杂，领域交叉严重， 就是无法对音视频这个方向形成一个系统性的认识，或者核心的流程流转不清楚。所以现在按照这个核心流程去看每个板块。 哈哈哈，流产的开始。

## 采集

  对应：数字信号、采样、量化、PCM、YUV、帧率码率、色彩空间、容器格式。
  
  搞清楚声音和视频是怎么变成数字的、为什么 CD 是 44.1kHz、为什么视频用 YUV 不用 RGB、MP4 文件里到底装了什么。
  听起来枯燥，但这是地基。不懂这些，你看 FFmpeg 文档就跟看天书一样。

## 前处理 

## 编码

  对应：音频编解码（MP3、AAC、Opus）+ 视频编解码原理（H.264、H.265、AV1）。
  
  理解 H.264 为什么能压缩这么狠、I 帧 P 帧 B 帧分别是什么、AAC 比 MP3 强在哪、心理声学模型这种"魔法"是怎么把音频压小 10 倍还能听的。
  
  你能看懂码流分析工具的输出，能理解一段视频为什么 1080p 文件大小差 10 倍、为什么会卡顿、为什么会有"格子"。这时候你才能跟同行用同一种"语言"对话。

## 封装

  FLV / MP4 / TS，根据传输协议选
  
  对应：FFmpeg 命令行 + C API + 视频处理 + 转码工程化
 FFmpeg 用得溜。不是只会复制粘贴别人的命令，而是看到一个新需求，能自己组合出 -vf、-filter_complex、-c:v、-preset 这些参数把它做出来。
 
 再进一步，能用 libavcodec 和 libavformat 写一个简易播放器，理解 AVFrame 和 AVPacket 的生命周期，知道 time_base 这个让无数人头疼的东西到底怎么换算。
 
 你已经能独立处理 80% 的离线音视频任务：转码、剪辑、推流、做工具链。绝大多数音视频工程师终其职业生涯停在这一境，而且这一境的人在市场上非常吃香。

## 传输

  对应：WebRTC + 实时通信 + 信令 + ICE + Simulcast + SFU
  
  搞定实时通信。WebRTC 不是一个东西，是一整套体系：
  
  信令：SDP、ICE、Offer/Answer，通话开始前那一堆"谈判"
  媒体：编码协商、Simulcast 多分辨率、SVC 
  分层编码网络：STUN/TURN 打洞、GCC/BBR 拥塞控制、NACK/FEC 抗丢包
  架构：SFU、MCU、Mesh 三种组网，
  
  各有适用场景一路修过来，你能独立从零搭一个 1 对 1 视频通话、能搞定多人会议系统、能解决移动端的回声黑屏问题。

## 服务端

  对应：流媒体协议体系 + CDN 调度 + 系统架构 + QoS 平衡个人战力强，开始能影响一片区域、调度一片势力。
  
  能从全局视角搭一个完整系统。直播、短视频、视频会议，每一类系统都有自己的架构。
  
  RTMP、HLS、DASH、SRT、LL-HLS 各有适用场景，CDN 怎么调度、回源怎么设计、动态加速怎么做、卡顿延迟画质这"三角难题"怎么平衡，全是这一境要解决的问题。
  
  你已经不是一个纯技术工程师了，更像架构师。要懂网络协议、要懂 CDN、要懂分布式、要懂运维，还得能跟产品和老板说清楚每个技术选择的成本和收益。

## 自己造工具

  对应：自己写编码器、改 FFmpeg 源码、深入研究压缩算法、做硬件加速。
  
  能自己实现一个简单的 H.264 编码器，能改 x264 源码做特定场景优化，能基于 NVENC/QSV/VideoToolbox 做硬件编码加速适配，能针对特定场景（比如游戏直播、屏幕共享）做编码器深度调优。

## 参与标准制定

  对应：参与 H.266/VVC、AV2、AVS3 等国际标准的制定和推进到这一境，你已经超出了工程师的范畴。
  你的工作开始影响全行业的演进方向。提一个标准的 proposal，全世界做这行的人都得跟着改代码。
  
  中国的腾讯、阿里、字节、华为，欧美的 Netflix、Google、Apple、Meta，这些公司都有人在做这一境的事。

## 推出标准

对应：推出影响全行业的开源项目或新一代编码标准x264 的作者 Loren Merritt、FFmpeg 的核心维护者团队、AV1 的主要贡献者，都是这个境界的人。

他们的代码和论文支撑了整个互联网视频生态。你刷的每一个抖音视频、看的每一场 B 站直播，背后都跑着他们写的代码。

## 定义未来

对应：开创全新的范式，比如把 AI 引入视频编码这一境只能仰望。

比如最近几年神经网络视频编码（Neural Video Coding）这个方向，谁能把它真正工程化、把压缩率再提一倍，谁就是下一代的"道祖"。

学术界、工业界都在卷这个方向，但目前离工业落地还有 5-10 年。新人不必焦虑，先把炼气和筑基做好。
