# 简介

  一直是用别人的agent，或者本地执行。其实在ai语音陪聊的时候， 我们对mcp的能力扩展，代码执行这些隔离内容，都没有做， 所以agent集群就是对话， 没有复杂的网络处理能力，工具处理能力。更不会考虑安全了。
  同行业的巨头，对话都会串线，我们至少在逻辑上进行了隔离。但是随着chat gpt app/网页，muse app等的出现，发现之前的agent 比玩具还玩具。但是我接触的一个老板，励志要把ai硬件陪聊做到chat gpt app那个水平，
  我大概估计了下， 要以亿为单位投入， 虽然营销及场景很好，但是目前技术很难达到。所以这个项目就先暂停了。
