# 简介

   VR、AR、MR、全息投影、裸眼3D。这是我们生活中已经现实存在的，但是他们的实现技术差别很大。

  我们可以用一句话来概括它们的终极差异：你是进入了虚拟世界，还是虚拟物体进入了你的世界？

#  核心概念对比看板

  为了让你建立最直观的认知，我们先来看它们在“虚实结合度”和“硬件依赖”上的差异：

  |技术|简称|一句话人话解释|核心硬件依赖|画面本质|
  |:--|--|--|--|--:|
|虚拟现实|VR|断开现实：你被塞进了一个 100% 纯虚拟的数字世界里。|"必须要戴不透明的头显（如 Meta Quest, Pico）"|纯数字渲染的世界|
|增强现实|AR,现实加层：在真实世界上面“漂浮”一层图表或提示信息。|智能眼镜、手机摄像头（如 Ray-Ban Meta）|2D/3D 的数据图层叠加|
|混合现实|MR|虚实融合：虚拟物体能“感知”现实物体，并在其上互动。|具备环境感知能力的头显（如 Vision Pro）|数字化重建的空间融合|
|裸眼 3D|—|视觉欺骗：不用戴眼镜，通过特定屏幕和透视让人感觉画面出屏。|折角 LED 大屏、光栅液晶屏,基于 2D 媒介的深度错觉|
|全息投影|—|光场重构：不用戴任何设备，物体直接“凭空”悬浮在三维空间中。|实验室激光干涉仪 / 商业代用品（反射膜）|真正的 3D 光学实体（真）|
